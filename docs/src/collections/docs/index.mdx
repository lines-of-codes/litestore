Welcome to litestore's documentation!

litestore is a fast, self-hostable, and open-source file storage platform 
licensed under the GNU GPLv3.

litestore has the following components:

- litestore server: API running with Bun
- litestore client: Vue.js web interface
- Garage: S3 storage solution
- PostgreSQL: The database
